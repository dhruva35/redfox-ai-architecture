SYSTEM ARCHITECTURE

The Redfox AI Autonomous Agent Architecture

How a 5-layer decoupled design achieves 0% false positives, strict scope compliance, and repeatable enterprise security assessments.

LAYER 1

User & Engagement Interface

Where clients schedule assessments, define targets, and upload assets. Built by the Fullstack Engineering team via robust REST/GraphQL APIs.

  • Engagement parameters (Target, Scope boundaries, Asset types)
  • Operational constraints (Read-only, Active scan, Maximum execution time)
  • Interactive dashboard with real-time audit event streaming
LAYER 2

Agent Core (LangGraph Reasoning Loop)

The cognitive loop that plans, acts, observes, and reflects. Implemented in LangGraph with a structured typed state model rather than chat history.

  • Planner: Hypothesizes next logical pen-test action using Groq/OpenAI
  • Scope Guard: Deterministic gate ensuring strict policy conformance
  • Reflector: Extracts evidence claims without hallucination
LAYER 3

Independent Verifier & Chain of Custody

The breakthrough module that guarantees 0% false positives. Runs in an isolated environment with zero access to the agent's chain-of-thought.

  • Receives only the claim and evidence parameters
  • Independently executes an isolated test to confirm or reject the vulnerability
  • Computes a cryptographic SHA-256 fingerprint for verifiable legal chain of custody
LAYER 4

Execution Sandbox (Containerized Tool Runner)

Where security tools actually execute. In production, tools execute within ephemeral, network-isolated containers destroyed immediately after use.

  • Read-only vs active scanning isolation
  • Strict CPU, memory, and timeout caps per execution
  • Normalized JSON output schema across all disparate security tools
LAYER 5

Skills & Knowledge (Methodology Skill Packs)

Declarative YAML skill packs that teach the agent specific testing methodologies (Web Apps, APIs, Cloud Infra, Active Directory) without retraining the model.

  • OWASP Top 10 web assessment recipes
  • Tool capability registry and parameter bindings
  • Dynamic context injection based on engagement phase
